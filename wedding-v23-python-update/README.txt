V23 Python update

1. Rozpakuj wedding-v23-python-update.zip.
2. Skopiuj folder wedding-v23-python-update do glownego katalogu projektu.
3. W katalogu projektu uruchom:

python wedding-v23-python-update/apply-v23.py
npm run build
npm start

Skrypt automatycznie:
- kopiuje kompletne zdjęcie samochodu,
- kopiuje pełny portret zaręczynowy,
- podmienia samochód na całe auto,
- dodaje portret do slajdu Wyczekiwane TAK,
- zachowuje zdjęcie dłoni, błyski i animowany refleks.

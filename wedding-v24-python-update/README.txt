V24 Python update

Wymagany projekt po V23.

1. Skopiuj folder wedding-v24-python-update do glownego katalogu projektu.
2. Uruchom:

python wedding-v24-python-update/apply-v24.py
npm run build
npm start

Zmiany:
- samochod jest ciasno wykadrowany po przezroczystosci,
- cale kola i opony sa widoczne,
- auto jedzie wyzej, bez zapadania pod droge,
- po slajdzie pelnego pakietu szczescia pojawia sie film,
- film ma podpis Błogosławieństwa Bożego! i kontrolki odtwarzania.

1. Skopiuj folder wedding-v6-update do katalogu glownego projektu.
2. Uruchom w katalogu projektu:
   python wedding-v6-update/apply-v6.py
3. Nastepnie:
   npm run build
   npm start

Później zdjęcie podróżnicze Ani zapisz jako:
public/images/ania-travel.jpg
Po jego dodaniu kolejna poprawka zastąpi placeholder.

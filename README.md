# Ania i Karol - animowana strona ślubna

## Uruchomienie

```bash
npm install
npm run build
npm start
```

Strona lokalna: `http://localhost:4200`

## Najważniejsze pliki

- `src/app/app.component.html` - tekst i kolejność scen
- `src/app/app.component.scss` - wygląd
- `src/app/app.component.ts` - animacje GSAP
- `public/images` - zdjęcia

## Uwagi

Zdjęcia źródłowe zostały odtworzone ze screenshotów. Do wersji finalnej warto użyć oryginalnych fotografii w pełnej jakości.

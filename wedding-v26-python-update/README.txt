V26 Python update

Wymagany projekt po V25.

1. Skopiuj folder wedding-v26-python-update do glownego katalogu projektu.
2. Uruchom:

python wedding-v26-python-update/apply-v26.py
npm run build
npm start

Zmiany:
- samochod jest nizej,
- opony wizualnie spoczywaja na jezdni,
- samochod jest lekko mniejszy,
- napis ma osobna, bezpieczna strefe u gory.

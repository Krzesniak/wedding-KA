V25 Python update

Wymagany projekt po V24.

1. Skopiuj folder wedding-v25-python-update do glownego katalogu projektu.
2. Uruchom:

python wedding-v25-python-update/apply-v25.py
npm run build
npm start

Zmiany:
- cale auto, kola i opony sa widoczne,
- auto jest ustawione wzgledem drogi przez bottom, nie przez top,
- nowe zdjecie dzieci zachowuje naturalne proporcje,
- fotografia korzysta z object-fit: contain,
- rozmyta kopia fotografii wypelnia wolna przestrzen karty.
